# 路面裂缝两层卷积 · 边缘分块尺寸选型演示

FastAPI + NumPy（全程 float64）实现的网页小工具：上传一张每边至多 512 像素的
灰度 PNG 和两层卷积的权重/偏置 JSON，在给定的第一层输入激活预算下，从
1～64 中选出预算允许的最大**方形输出分块边长**，并分别用分块推理和独立整图
基准跑分，报告峰值用量、最大绝对误差及其坐标，误差 > 1e-8 判失败。

## 网络结构（固定）

| 层 | 通道 | 核 | 步长 | 膨胀 | 零填充 | 激活 |
|---|---|---|---|---|---|---|
| layer1 | 1 → 4 | 3×3 | 2 | 1 | 1 | ReLU |
| layer2 | 4 → 1 | 3×3 | 1 | 2 | 2 | — |

## 预算口径与选型规则

- 对每个输出分块（边缘块按实际输出尺寸**裁短**），沿两层感受野链路反推出
  覆盖它所需的**图内激活最小矩形窗口**，元素数 = 窗口高 × 窗口宽 × 输入通道数；
  图外零填充不物化、不计入。
- 窗口公式（layer2 dilation 2 使单输出在 layer1 输出上跨度 `[i−2, i+2]`，
  layer1 stride 2 再映射到输入）：
  行窗口 `[2·r0−5, 2·(r1−1)+6)`，列窗口同理，最后裁到图界。
- 边长 `s` 的峰值 = 该 s 下所有分块窗口元素数的最大值（内部块通常最大，
  边缘块被图界裁短）。从 1～64 中选峰值 ≤ 预算的最大 s。
- 实跑时分块路径截取的正是同一窗口；流水线对“实跑峰值 == 规划峰值且
  ≤ 预算”做硬性断言，守住预算。
- 当单像素块（s=1）仍超预算时，**不执行推理**，只返回最低所需预算。

## 运行方式

### Docker Compose（推荐）

```bash
docker compose up --build
# 灰度偏移保持区间 → http://localhost:8000（主）
# 分块选型演示    → http://localhost:8001
```

```bash
pip install -r requirements.txt
uvicorn app.web:app   --host 0.0.0.0 --port 8000   # 灰度偏移保持区间
uvicorn app.main:app  --host 0.0.0.0 --port 8001   # 分块选型演示
```

## 灰度偏移 d 的判定保持区间

页面（`app.web`，Compose 中映射到 8000 端口）：上传每边 ≤128 像素的灰度 PNG
和原权重 JSON，点“加载并显示输出网格”后在模型输出网格上点选 1～8 个复核点；
服务端对图内归一化灰度统一加偏移 `d ∈ [−0.25, 0.25]`，截到 `[0,1]` 后按原
两层卷积计算（图外零填充仍为零），分数 `≥ 0` 记为裂缝，求包含 `d=0` 的最大
连续区间使所有复核点保持原判。

- **精确求解，不做网格扫描**：固定权重后每个输出分数是
  `clip(x_k + d, 0, 1)` 的线性组合，layer1 的 ReLU 在固定截断状态下也仍是
  线性；所以分数对 d 分段线性，折点只可能是 `d = −x_k`、`d = 1 − x_k`，或
  某 layer1 预激活的零点。用 `Fraction` 精确表示所有 float 参数，折点/零点
  与端点比较无浮点误差。
- 从 `d=0` 向两侧逐段推进，遇到第一个判定翻转（含分数恰好触零的切触）即
  截断；**翻转后即使恢复，中间仍算越界**。
- 端点能否取到按精确分数判定：`≥0` 即可取（闭端点），否则不可取（开端点）。
  每个端点报告是否到达 ±0.25 的范围边界，以及由哪些复核点限制（附该点在
  d=0、端点、端点外的分数）。端点还会用现有 float64 流水线复算，若因根值
  舍入而结果不同会在页面 notes 中提示。
- **失败即清空**：选点非法、超范围、JSON/图像不合法或计算异常时，返回
  `interval = null` 并在页面显示“计算失败，旧区间已清空”及原因。
- 勾选“以 JSON 返回”可直接脚本调用 `/sweep`；`/grid` 返回输出网格的
  原判与分数，供页面绘制。

### 权重 JSON 格式

```json
{
  "layer1": {"weight": [[[[...3x3...]]]], "bias": [0, 0, 0, 0]},
  "layer2": {"weight": [...形状 1x4x3x3...], "bias": [0]}
}
```
形状要求：layer1.weight `(4,1,3,3)`、layer1.bias `(4,)`、
layer2.weight `(1,4,3,3)`、layer2.bias `(1,)`。

### 样例

`scripts/make_samples.py` 生成确定性样例（已随仓库提供于 `samples/`）：

```bash
python3 -I scripts/make_samples.py samples
# sample_crack_64.png（64×64 裂缝灰度图）
# sample_random_8.png（8×8 随机图，便于手工核对窗口）
# sample_crack_128.png（128×128，用于灰度偏移页面上限）
# weights.json（两层权重与偏置）
```

页面上传两个文件并填入预算（元素数）即可；勾选“以 JSON 返回”便于脚本调用。
